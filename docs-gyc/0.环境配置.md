## 环境备份

已导出当前完整环境配置，可用于快速恢复或在其他机器上复现环境：

### 文件清单

- **`environment.yml`** - Conda 环境配置（包含 conda 包和 Python 版本）
- **`requirements-freeze.txt`** - pip freeze 输出（精确版本，138个包）
- **`pip-list.txt`** - pip list 输出（可读格式，138个包）
- **`uv.lock`** - uv 锁文件（项目根目录，完整依赖树）

### 恢复环境

**方法 1：使用 conda + uv（推荐，与原安装方式一致）**
```bash
# 创建 conda 环境
conda env create -f docs-gyc/environment.yml

# 激活环境并用 uv 安装依赖
conda activate cosmos-predict2.5
uv sync --extra=cu128 --active --inexact
```

**方法 2：仅使用 pip（备用方案）**
```bash
conda create -n cosmos-predict2.5 python=3.10 -y
conda activate cosmos-predict2.5
pip install -r docs-gyc/requirements-freeze.txt
```
