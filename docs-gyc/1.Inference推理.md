## 推理命令

### 快速开始（推荐）

使用本地权重推理（已配置 HF 缓存）：

```bash
conda activate cosmos-predict2.5
bash scripts/inference_local.sh
```

### 基础推理（单 GPU）

```bash
conda activate cosmos-predict2.5

# Image2World - 图片生成视频
python examples/inference.py \
  -i assets/base/robot_welding.json \
  -o outputs/image2world \
  --inference-type=image2world

# Video2World - 视频续写
python examples/inference.py \
  -i assets/base/robot_pouring.json \
  -o outputs/video2world \
  --inference-type=video2world

# Text2World - 文本生成视频
python examples/inference.py \
  -i assets/base/bus_terminal.json \
  -o outputs/text2world \
  --inference-type=text2world
```

### 多 GPU 推理（8 卡）

```bash
torchrun --nproc_per_node=8 examples/inference.py -i assets/base/robot_pouring.json -o outputs/base_video2world --inference-type=video2world
```

### 推理类型

| 类型 | 参数 | 说明 |
|------|------|------|
| Text2World | `--inference-type=text2world` | 文本生成视频 |
| Image2World | `--inference-type=image2world` | 图片生成视频 |
| Video2World | `--inference-type=video2world` | 视频续写 |

### 模型选择

| 模型 | 参数 | 备注 |
|------|------|------|
| 2B | `--model=2B/post-trained` | 默认 |
| 2B/distilled | `--model=2B/distilled --inference-type=text2world` | 仅支持 Text2World |
| 14B | `--model=14B/post-trained` | 需要更多显存 |

### 自回归长视频生成

```bash
python examples/inference.py -i assets/base/bus_terminal_long.json -o outputs/autoregressive
```

### 测试 1：Image2World 推理 ✅

**执行脚本：**

```bash
conda activate cosmos-predict2.5
bash scripts/inference_local.sh
```

**关键配置：**

1. **HuggingFace 缓存结构**（使用本地权重，避免重复下载）：
   ```bash
   # Predict2.5-2B
   /root/.cache/huggingface/hub/models--nvidia--Cosmos-Predict2.5-2B/
   ├── refs/main  # 包含 revision: 6787e176dce74a101d922174a95dba29fa5f0c55
   └── snapshots/6787e176dce74a101d922174a95dba29fa5f0c55/
       → 软链接到 /mnt/gyc/gyc_ckp/models/Cosmos-Predict2.5-2B
   
   # Reason1-7B
   /root/.cache/huggingface/hub/models--nvidia--Cosmos-Reason1-7B/
   ├── refs/main  # 包含 revision: 3210bec0495fdc7a8d3dbb8d58da5711eab4b423
   └── snapshots/3210bec0495fdc7a8d3dbb8d58da5711eab4b423/
       → 软链接到 /mnt/gyc/gyc_ckp/models/Cosmos-Reason1-7B
   ```

2. **Guardrail1 权限**：
   - 需要在 https://huggingface.co/nvidia/Cosmos-Guardrail1 申请访问权限
   - 申请通过后执行 `huggingface-cli login` 登录

3. **环境变量**：
   ```bash
   export http_proxy=http://192.168.32.28:18000
   export https_proxy=http://192.168.32.28:18000
   unset HF_HUB_OFFLINE  # 允许 HF 访问本地缓存
   ```

**执行结果：**
- 成功从本地缓存加载 Predict2.5-2B 和 Reason1-7B 权重
- Guardrail1 首次下载后缓存到本地（约 500MB）
- 生成耗时：约 12 分钟（36 步迭代，单卡 A800）
- 输出视频：`outputs/test_image2world/robot_welding.mp4`

**性能数据：**
- GPU 利用率：100%
- 显存占用：28GB / 80GB
- 迭代速度：19.45s/it
- 总步数：36 steps

**注意事项：**
- ❌ 不要使用 `--checkpoint-path` 参数指定模型目录（会导致路径解析错误）
- ✅ 让代码自动从 HuggingFace 缓存加载（已通过软链接配置本地权重）
