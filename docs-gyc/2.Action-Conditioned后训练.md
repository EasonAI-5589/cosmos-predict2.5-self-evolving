### 输入数据格式

**目录结构**：
```
assets/action_conditioned/basic/bridge/
├── annotation/test/
│   ├── 0.json
│   ├── 1.json
│   └── ...
└── videos/test/
    ├── 0/rgb.mp4
    ├── 1/rgb.mp4
    └── ...
```

**JSON 标注格式**（`0.json`）：
```json
{
  "task": "robot_trajectory_prediction",
  "texts": ["move the spatula to the far left corner behind the pot"],
  "videos": [{"video_path": "videos/test/0/rgb.mp4"}],
  "action": [
    [dx, dy, dz, droll, dpitch, dyaw, gripper],  // 第1帧
    [dx, dy, dz, droll, dpitch, dyaw, gripper],  // 第2帧
    ...
  ],
  "continuous_gripper_state": [0.0, 0.0, 0.5, ...],
  "episode_id": "0"
}
```

**Action 维度定义**（7 维）：
- `dx, dy, dz` (3) - 末端执行器位置增量
- `droll, dpitch, dyaw` (3) - 末端执行器姿态增量（欧拉角）
- `gripper` (1) - 夹爪命令（0=打开，1=关闭）

**可选：四元数表示**（设置 `use_quat=True`）：
- `dx, dy, dz` (3) - 位置增量
- `qx, qy, qz, qw` (4) - 姿态（四元数）
- `gripper` (1) - 夹爪命令

### 推理参数

**配置文件**（`inference_params.json`）：
```json
{
  "name": "basic",
```

**关键参数说明**：
- `chunk_size`: 12 - 生成 12 帧视频
- `num_steps`: 35 - 去噪步数
- `resolution`: "256,320" - 输出分辨率
- `guidance`: 0 - 引导强度

### 原生支持的输入类型

#### 1. 数据格式要求

**必需文件**：
- JSON 标注文件：包含动作序列、文本描述、视频路径
- 视频文件（MP4）：用于提取初始条件帧

**目录结构规范**：
```
input_root/
├── annotation/
│   └── test/  # 或 train/val
│       ├── 0.json
│       └── ...
└── videos/
    └── test/
        ├── 0/rgb.mp4
        └── ...
```

#### 2. 动作表示方式

**默认：7维欧拉角**
- `[dx, dy, dz, droll, dpitch, dyaw, gripper]`
- 位置增量 (3) + 姿态增量欧拉角 (3) + 夹爪 (1)

**可选：四元数表示**（`use_quat=True`）
- `[dx, dy, dz, qx, qy, qz, qw, gripper]`
- 位置增量 (3) + 姿态四元数 (4) + 夹爪 (1)

#### 3. 可配置参数

**生成参数**：
- `chunk_size` (默认12) - 生成帧数
- `resolution` (如 "256,320") - 输出分辨率
- `num_steps` (默认35) - 去噪步数
- `guidance` (默认7) - 引导强度

**动作参数**：
- `action_scaler` (默认20.0) - 动作缩放系数
- `gripper_scale` (默认1.0) - 夹爪缩放系数
- `use_quat` (默认False) - 是否使用四元数

**数据参数**：
- `camera_id` (默认0) - 相机ID（多相机场景）
- `fps_downsample_ratio` (默认1) - FPS降采样比例
- `num_latent_conditional_frames` (默认1) - 条件帧数量（0/1/2）

#### 4. 自定义扩展

**自定义动作加载函数**：
```bash
# 通过 action_load_fn 参数指定自定义加载函数
python examples/action_conditioned.py \
  --action-load-fn="custom_module.load_action" \
  ...
```

用途：支持不同的动作表示或数据格式（如 RoboTwin）

## 阶段 2：RoboTwin 后训练

### 核心任务

#### 1. 自定义生成参数
- **帧数**：官方 Bridge 数据集使用 13 帧（`num_action_per_chunk=12`，生成 12 帧 + 1 条件帧）
- **分辨率**：官方使用 256x320 或 480x640
- **目标**：根据 RoboTwin 数据调整，尽量不要与官方设定差太多

#### 2. 去噪步数缩减（蒸馏）
- **问题**：推理时需要大量去噪步数（默认 35 步），部署成本高
- **方案**：使用 DMD2 框架进行蒸馏，将步数降至 4 步
- **参考**：`docs/distillation.md`

#### 3. Action 维度扩展（核心）
- **当前**：Bridge 数据集使用 7 维 Action
  - `ee xyz (3)` - 末端执行器位置
  - `ee euler (3)` - 末端执行器姿态（欧拉角）
  - `gripper (1)` - 夹爪开合状态
- **目标**：扩展到 14 维以支持双臂机器人
- **关键文件**：
  - `cosmos_predict2/_src/predict2/action/datasets/dataset_local.py:137` - Action 维度定义
  - `cosmos_predict2/_src/predict2/action/networks/action_conditioned_minimal_v1_lvg_dit.py:52` - 网络 Action 输入维度
  - `cosmos_predict2/_src/predict2/action/configs/action_conditioned/experiment/exp_2B_action_conditioned_rectify_flow.py:602` - 实验配置

### 官方配置参考

#### Bridge 数据集配置

**数据格式**（`datasets/bridge/`）：
```
bridge/
├── annotations/
│   ├── *.json  # 每帧的 state、action、gripper_state
├── videos/
    ├── *.mp4
```

**JSON 标注内容**：
- `state`: 末端执行器姿态 [x, y, z, roll, pitch, yaw]
- `continuous_gripper_state`: 夹爪宽度（0=开，1=闭）
- `action`: 夹爪位移 [dx, dy, dz, droll, dpitch, dyaw, gripper_cmd]

**训练配置**（13 帧 256x320）：
```python
bridge_13frame_480_640_train_dataset = L(Dataset_3D)(
    video_path="datasets/bridge/",
    fps_downsample_ratio=1,
    num_action_per_chunk=12,  # 生成 12 帧
    cam_ids=[0],
    accumulate_action=False,
    video_size=[256, 320],  # 或 [480, 640]
    mode="train",
)
```

#### 训练命令

```bash
torchrun --nproc_per_node=1 --master_port=12341 \
  -m scripts.train \
  --config=cosmos_predict2/_src/predict2/action/configs/action_conditioned/config.py \
  -- experiment=ac_reason_embeddings_rectified_flow_2b_256_320 \
  ~dataloader_train.dataloaders
```

**关键配置**（`exp_2B_action_conditioned_rectify_flow.py`）：
```python
AC_REASON_EMBEDDINGS_RECTIFIED_FLOW_2B_256_320 = LazyDict(
    dict(
        defaults=[
            {"override /model": "action_conditioned_video2world_fsdp_rectified_flow"},
            {"override /net": "cosmos_v1_2B_action_conditioned"},
            {"override /conditioner": "action_conditioned_video_conditioner"},
            {"override /data_train": "bridge_13frame_480_640_train"},
            {"override /data_val": "bridge_13frame_480_640_val"},

        job=dict(
            group="cosmos_predict_v2p5",
            name="2b_bridge_action_conditioned",
            project="cosmos_predict2_action_conditioned",
        ),
        optimizer=dict(
            lr=2 ** (-14.5),  # 3.05e-05
            weight_decay=0.1,
        ),
        model=dict(
            config=dict(
                net=dict(
                    action_dim=7,  # ← 需要改成 14

            ),
        ),
    ),

```

#### Checkpoint 输出

默认路径：`${IMAGINAIRE_OUTPUT_ROOT}/PROJECT/GROUP/NAME/checkpoints`
- `IMAGINAIRE_OUTPUT_ROOT` 默认为 `/tmp/imaginaire4-output`
- 建议设置到有足够空间的目录

示例输出：
```
/tmp/imaginaire4-output/
└── cosmos_predict2_action_conditioned/
    └── cosmos_predict_v2p5/
        └── 2b_bridge_action_conditioned/
            └── checkpoints/
                ├── latest_checkpoint.txt
                └── <iter>/
                    └── model/  # DCP 格式
```

#### Checkpoint 转换

训练后需要将 DCP 格式转换为 PyTorch 格式：

```bash
CHECKPOINTS_DIR=${IMAGINAIRE_OUTPUT_ROOT:-/tmp/imaginaire4-output}/cosmos_predict2_action_conditioned/cosmos_predict_v2p5/2b_bridge_action_conditioned/checkpoints
CHECKPOINT_ITER=$(cat $CHECKPOINTS_DIR/latest_checkpoint.txt)
CHECKPOINT_DIR=$CHECKPOINTS_DIR/$CHECKPOINT_ITER

# 转换
python ./scripts/convert_distcp_to_pt.py $CHECKPOINT_DIR/model $CHECKPOINT_DIR
```

生成文件：
- `model.pt` - 完整权重
- `model_ema_fp32.pt` - EMA 权重（FP32）
- `model_ema_bf16.pt` - EMA 权重（BF16，推荐推理使用）

#### 推理命令

```bash
python examples/action_conditioned.py \
  -i assets/action_conditioned/basic/inference_params.json \
  -o outputs/action_conditioned/basic \
  --config-file cosmos_predict2/_src/predict2/action/configs/action_conditioned/config.py \
  --checkpoint-path $CHECKPOINT_DIR/model_ema_bf16.pt \
  --experiment ac_reason_embeddings_rectified_flow_2b_256_320
```

### 蒸馏（Distillation）

#### 目标
将去噪步数从 35 步降至 4 步，提升推理速度。

#### 训练命令

```bash
torchrun --nproc_per_node=1 --master_port=12341 \
  -m scripts.train \
  --config=cosmos_predict2/_src/interactive/configs/registry_predict2p5.py \
  -- experiment=dmd2_trigflow_distill_cosmos_predict2_2B_action_conditioned_bridge_13frame_256x320_no_s3
```

#### 蒸馏后推理

```bash
python examples/action_conditioned.py \
  -i assets/action_conditioned/basic/inference_params.json \
  -o outputs/action_conditioned/basic \
  --config-file cosmos_predict2/_src/interactive/configs/registry_predict2p5.py \
  --checkpoint-path $CHECKPOINT_DIR/model_ema_bf16.pt \
  --experiment dmd2_trigflow_distill_cosmos_predict2_2B_action_conditioned_bridge_13frame_256x320_no_s3 \
  --num-steps 4  # ← 使用 4 步去噪
```
