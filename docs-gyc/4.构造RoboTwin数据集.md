## 关键技术细节

### 1. 训练代码如何使用 state 和 action

**重要**：训练代码（`dataset_local.py`）不直接读 JSON 里的 `action` 字段，而是从 `state` 实时计算相对变换：

```python
# _get_robot_states：读 state 前 6 维（不含 gripper）
arm_states = states[:, :6]   # 6维：xyz + roll,pitch,yaw
gripper_states = cont_gripper_states  # 单独读

# _get_actions：计算相邻帧的相对变换（不是简单差值！）
rel_xyz = prev_rotm.T @ (curr_xyz - prev_xyz)   # 在上一帧坐标系下的平移
rel_rotm = prev_rotm.T @ curr_rotm               # 相对旋转
rel_rpy = rotm2euler(rel_rotm)                   # 转成欧拉角
action[k] = [rel_xyz(3), rel_rpy(3), curr_gripper(1)]
```

所以 JSON 里只需要提供 `state`（绝对位姿，欧拉角），action 由代码自动计算。

### 2. 四元数 → 欧拉角 转换

RoboTwin 存的是四元数 `[x, y, z, qw, qx, qy, qz]`，需要转成欧拉角 `[x, y, z, roll, pitch, yaw]`：

```python
import transforms3d as t3d

def quat_to_euler(endpose):
    # endpose: [x, y, z, qw, qx, qy, qz]
    xyz = endpose[:3]
    quat = endpose[3:]  # [qw, qx, qy, qz]
    rotm = t3d.quaternions.quat2mat(quat)
    rpy = t3d.euler.mat2euler(rotm, axes='sxyz')  # [roll, pitch, yaw]
    return np.concatenate([xyz, rpy])
```

### 3. 14 维 state 的拼接方式

```python
left_euler  = quat_to_euler(left_endpose[i])   # [x,y,z,r,p,y]
right_euler = quat_to_euler(right_endpose[i])  # [x,y,z,r,p,y]
left_g  = left_gripper[i]
right_g = right_gripper[i]

state[i] = np.concatenate([left_euler, right_euler, [left_g, right_g]])
# shape: (14,)
```

### 4. 模型改动（为什么 14 维完全可行）

网络里 action 的处理方式是把整个 chunk（12帧 × action_dim）展平后过一个 MLP：

```python
# 展平：[B, 12, 14] → [B, 1, 168]
action = rearrange(action, "b t d -> b 1 (t d)")
# MLP 映射到 model_channels
action_emb = self.action_embedder_B_D(action)
# 加到 timestep embedding 上
t_embedding = t_embedding + action_emb
```

模型对 action 维度没有任何硬编码假设，`action_dim` 改成 14 只影响 MLP 的输入层大小，其他不变。
