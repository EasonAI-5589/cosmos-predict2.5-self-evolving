# 5. RoboTwin Action-Conditioned 后训练

## 目标

用 Rectified Flow 训练方法，在 RoboTwin 双臂数据上对 Cosmos-Predict2.5 做后训练，让模型能根据 14 维 action 条件生成对应的机器人操作视频。

---

## 一、后训练完整调用链

训练命令：
```bash
torchrun --nproc_per_node=1 --master_port=12341 \
  -m scripts.train \
  --config=cosmos_predict2/_src/predict2/action/configs/action_conditioned/config.py \
  -- experiment=ac_reason_embeddings_rectified_flow_2b_256_320 \
  ~dataloader_train.dataloaders
```

### 调用流程

```
bash 命令
│
│  torchrun -m scripts.train --config=.../config.py -- experiment=ac_...
│
▼
① scripts/train.py                          ← 入口，一行代码
   └→ cosmos_oss/scripts/train.py:main()    ← 真正的 main

      ▼ 解析参数 + 加载配置
② config.py (action_conditioned/config.py)   ← 注册所有组件
   ├→ register_model()        注册模型类
   ├→ register_net()          注册网络类（含 action MLP）
   ├→ register_conditioner()  注册条件器（含 action 透传）
   ├→ register_training_and_val_data()  注册数据集
   └→ import experiments/base/action.py  加载实验超参数

      ▼ 创建模型 + 加载权重
③ cosmos_oss/scripts/train.py:launch()
   │
   ├→ download_checkpoint(load_path)         下载/定位预训练权重
   │
   ├→ create_model_from_consolidated_checkpoint_with_fsdp()
   │   └→ 实例化模型: ActionVideo2WorldModelRectifiedFlow
   │       ├→ 内含 net: ActionChunkConditionedMinimalV1LVGDiT (DiT + action MLP)
   │       ├→ 内含 conditioner: ActionConditionedConditioner
   │       └→ 内含 tokenizer: 视频编解码器
   │   └→ 加载 .pt 权重 (strict=False, action MLP 随机初始化)
   │
   ├→ instantiate(dataloader_train)          创建数据加载器
   │   └→ Dataset_3D                         Bridge 数据集
   │       读取 annotation JSON + video MP4
   │       计算 action (从 state 得到相对变换)
   │
   └→ trainer.train(model, dataloader_train, dataloader_val)

      ▼ 训练循环
④ imaginaire/trainer.py:train()
   │
   ├→ model.init_optimizer_scheduler()       创建优化器 (AdamW)
   ├→ checkpointer.load()                    加载 checkpoint（如果是恢复训练）
   │
   └→ for iteration in range(max_iter):      训练主循环
       │
       ├→ data = next(dataloader)            取一个 batch
       │   data = {
       │     "video": [B, C, T, H, W],       视频帧
       │     "action": [B, 12, 7],            动作序列
       │     "t5_text_embeddings": ...,       文本 embedding
       │     "fps": ...,
       │   }
       │
       ├→ trainer.training_step()
       │   └→ model.training_step(data)
       │
       │      ▼ 模型前向传播
⑤     │      model.forward(data_batch)
       │      │
       │      ├→ conditioner(data_batch)                提取条件信息
       │      │   └→ ActionConditionedCondition(
       │      │        text_emb, action, video_mask, ...)
       │      │
       │      ├→ tokenizer.encode(video)                视频 → latent
       │      │   video [B,C,T,H,W] → latent [B,16,T',H',W']
       │      │
       │      ├→ 加噪声 (Rectified Flow)
       │      │   xt = t * noise + (1-t) * x0
       │      │
       │      ├→ net(xt, timestep, condition)            DiT 前向
       │      │   └→ ActionChunkConditionedMinimalV1LVGDiT.forward()
       │      │       ├→ action [B,12,7]
       │      │       │   → reshape [B,3,28]  (按时间压缩比4分组)
       │      │       │   → MLP → action_emb [B,3,2048]
       │      │       │   → 补零 → [B,4,2048]
       │      │       ├→ t_embedding += action_emb       ★ action 注入
       │      │       ├→ adaln_lora += action_emb
       │      │       ├→ DiT Blocks × 28 层
       │      │       └→ 输出: velocity prediction
       │      │
       │      └→ loss = MSE(predicted_velocity, target_velocity)
       │
       ├→ loss.backward()                    反向传播
       ├→ optimizer.step()                   更新参数
       │
       └→ 每 2000 步 → checkpointer.save()  保存 checkpoint (DCP 格式)
```

## 二、RoboTwin 适配需要做的事

### 改动 1：新建 Dataset 类

**文件**：`cosmos_predict2/_src/predict2/action/datasets/dataset_local.py`（新建子类或新文件）

需要修改的部分：

| 项目 | Bridge (原始) | RoboTwin (目标) |
|------|-------------|----------------|
| `action_dim` | 7 | 14 |
| `c_act_scaler` | `[20.0]*6 + [gripper]` (7个值) | `[20.0]*6 + [gripper]` × 2 (14个值) |
| `_get_robot_states()` | `states[:, :6]` 取单臂 | 取双臂各 6 维 |
| `_get_actions()` | 计算单臂相对变换 | 分别计算左右臂相对变换后拼接 |

### 改动 2：新建实验配置

**文件**：`cosmos_predict2/experiments/base/action.py`（新增配置）

```python
# 新增 RoboTwin 实验配置
ac_robotwin_rectified_flow_2b_256_320 = LazyDict(dict(
    defaults=[...],
    checkpoint=dict(
        load_path="/root/.cache/huggingface/hub/.../robot/action-cond/38c6c645-..._ema_bf16.pt",
        #          ↑ 改成本地路径
        strict_resume=False,
    ),
    model=dict(config=dict(
        net=dict(
            action_dim=14,               # ← 7 改为 14
            temporal_compression_ratio=4,
        ),
    )),
    dataloader_train=dict(
        batch_size=8,
        dataset=dict(
            num_action_per_chunk=12,
            video_size=[256, 320],
        ),
    ),
))
```

### 改动 3：新建数据配置

**文件**：`cosmos_predict2/_src/predict2/action/configs/action_conditioned/data.py`（新增注册）

新增 RoboTwin 数据集的 dataloader 并注册到 ConfigStore。

### 改动 4：推理 action 加载函数

**文件**：`cosmos_predict2/action_conditioned.py`（新增函数）

新增 `load_robotwin_action_fn`，支持 14 维双臂 action 的加载和缩放。
