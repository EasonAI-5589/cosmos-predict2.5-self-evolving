# 6. RoboTwin 后训练 — 配置继承陷阱与适配指南

## 一、背景

本文记录在 RoboTwin 双臂 14D 数据上做 Action-Conditioned 后训练时遇到的三个配置问题，分析根本原因，并给出完整的适配步骤。

---

## 二、Hydra LazyDict 配置继承机制

理解问题的前提是理解这套系统是怎么合并配置的。

### 继承链

```
T2V_REASON_EMBEDDINGS_..._RECTIFIED_FLOW   ← 祖父实验（文生视频训练用，含 S3、straggler）
    ↓ 继承
AC_REASON_EMBEDDINGS_RECTIFIED_FLOW_2B     ← 父实验（Bridge 单臂 action-conditioned）
    ↓ 继承
AC_ROBOTWIN_14D_RECTIFIED_FLOW_2B          ← 子实验（我们的 RoboTwin 实验）
```

### 关键规则

配置合并分两个独立层次：

**层次 1：group override（`{"override /xxx": "yyy"}`）**
- 替换某个配置组的**基础结构**（schema）
- 例：`{"override /checkpoint": "local"}` 把 checkpoint 的基础从 `CHECKPOINT_S3` 换成 `CHECKPOINT_LOCAL`
- **只改基础，不清除父实验的字段覆盖**

**层次 2：dict 字段覆盖（`checkpoint=dict(...)`）**
- 在基础结构之上，按层次从祖先到子孙**逐层合并**
- 每一层只覆盖自己写了的字段，不会删除祖先写的字段

这意味着：**即使你用 group override 换了基础，祖先实验的 dict 字段覆盖依然会叠加上去。**

## 三、遇到的三个报错及修复

### 报错 1：S3 boto3 凭证为空

```
ValueError: Cannot create profile from empty legacy Boto3 config
```

**根本原因：**

`AC_ROBOTWIN_14D_RECTIFIED_FLOW_2B` 用了 `{"override /checkpoint": "local"}`，把基础换成了
`CHECKPOINT_LOCAL`（`enabled=False`）。但祖父实验 `T2V_...` 在 checkpoint dict 里写了：

```python
checkpoint=dict(
    save_to_object_store=dict(enabled=True),
    load_from_object_store=dict(enabled=True),
    ...
)
```

这两个 `enabled=True` 在 Hydra 合并时覆盖了 `CHECKPOINT_LOCAL` 的 `False`，导致最终
`enabled=True` 但 `credentials=""` 为空字符串，boto3 报错。

**修复：** 在子实验的 checkpoint dict 里显式覆盖回 `False`：

```python
# exp_2B_action_conditioned_rectify_flow.py — AC_ROBOTWIN_14D_RECTIFIED_FLOW_2B
checkpoint=dict(
    load_path="...",
    load_training_state=False,
    strict_resume=False,
    save_to_object_store=dict(enabled=False),   # ← 新增：覆盖祖父的 True
    load_from_object_store=dict(enabled=False),  # ← 新增：覆盖祖父的 True
),
```

---

### 报错 2：straggler 包未安装

```
RuntimeError: Please install straggler package before using StragglerDetectionV2.
```

**根本原因：**

祖父实验 `T2V_...` 在 trainer dict 里设了 `straggler_detection=dict(enabled=True)`，这是
NVIDIA 内部集群专用的分布式训练监控包，外部环境没有。合并时这个配置被继承下来。

**修复：** 在子实验的 trainer dict 里显式禁用：

```python
# exp_2B_action_conditioned_rectify_flow.py — AC_ROBOTWIN_14D_RECTIFIED_FLOW_2B
trainer=dict(
    straggler_detection=dict(enabled=False),  # ← 新增
),
```

---

### 报错 3：HeartBeat / IterSpeed / DeviceMonitor 尝试写 S3

```
File "callbacks/heart_beat.py", line 57: easy_io.dump(info, f"s3://rundir/...")
ValueError: Must specify exactly one of profile or s3_credential_path
```

**根本原因：**

`BASIC_CALLBACKS` 中的 `HeartBeat`、`IterSpeed`、`DeviceMonitor` 的 `save_s3` 参数都绑定到：

```python
save_s3="${upload_reproducible_setup}"
```

祖父实验设了 `upload_reproducible_setup=True`，这个顶层字段被继承下来，
导致所有这些 callback 都尝试往 `s3://rundir/` 写文件。

**修复：** 在子实验顶层显式覆盖为 `False`：

```python
upload_reproducible_setup=False,  # disable S3 uploads (no cloud storage in local env)
```

---

### 报错 4：EveryNDrawSample（可视化采样）尝试写 S3

```
File "callbacks/every_n_draw_sample.py", line 209: easy_io.dump(info, f"s3://rundir/...")
ValueError: Must specify exactly one of profile or s3_credential_path
```

**根本原因：**

`viz_online_sampling` callbacks group 注册时 `save_s3=True` 是**硬编码**的：

```python
VIZ_ONLINE_SAMPLING_CALLBACKS = dict(
    every_n_sample_reg=L(EveryNDrawSample)(every_n=5000, save_s3=True, ...),
    every_n_sample_ema=L(EveryNDrawSample)(every_n=5000, save_s3=True, ...),
)
```

父实验只覆盖了 `every_n`、`guidance` 等字段，没有覆盖 `save_s3`，所以到触发步数时仍会尝试写 S3。

**修复：**

```python
trainer=dict(
    callbacks=dict(
        every_n_sample_reg=dict(save_s3=False),
        every_n_sample_ema=dict(save_s3=False),
    ),
),
```

---

### 报错 5：DataLoader 收到意外参数 `dataloaders`

```
TypeError: DataLoader.__init__() got an unexpected keyword argument 'dataloaders'
```

**根本原因：**

祖父实验的 `dataloader_train` 使用的是 `IterativeJointDataLoader`，其配置结构是：

```python
dataloader_train=dict(
    dataloaders=dict(
        image_data=dict(...),
        video_data=dict(...),
    ),
)
```

子实验用了 `{"override /data_train": "robotwin_13frame_train"}` 把基础换成普通
`torch.utils.data.DataLoader`，但祖父实验 dict 里的 `dataloaders` 键依然通过 Hydra
合并附加进来，导致 `DataLoader` 收到它不认识的 `dataloaders` 参数。

**修复：** 在训练命令里用 `~` 语法显式删除这个键：

```bash
-- experiment=cosmos_predict2p5_2B_action_conditioned_rectified_flow_robotwin_14d_13frame_256x320 \
   ~dataloader_train.dataloaders
```

`~key` 是 Hydra 的删除覆盖语法，在 config 完成合并后强制移除指定键。

> **注意：** 这个 `~dataloader_train.dataloaders` 在 Bridge 实验的注释里也有，但脚本里漏掉了。
> 凡是从 `T2V_...` 祖父实验继承的 action-conditioned 子实验，训练命令里都需要这一项。

## 四、完整的适配清单

从零开始做一个新数据集的 Action-Conditioned 后训练，需要修改以下文件：

### 必须修改的文件

| 文件 | 修改内容 |
|------|----------|
| `cosmos_predict2/_src/predict2/action/datasets/dataset_local.py` | 新增/修改 Dataset 类，适配新的 `action_dim` 和数据格式 |
| `cosmos_predict2/_src/predict2/action/configs/action_conditioned/data.py` | 新增数据集路径配置和 DataLoader，注册到 ConfigStore |
| `cosmos_predict2/_src/predict2/action/configs/action_conditioned/experiment/exp_2B_action_conditioned_rectify_flow.py` | 新增实验配置（`LazyDict`），设置超参数 |
| `scripts/train_robotwin_14d.sh`（或新建脚本） | 启动命令，必须包含 `~dataloader_train.dataloaders` |

### 实验配置的必填项（继承陷阱对应的修复项）

新建任何从 `T2V_...` 或 `AC_REASON_EMBEDDINGS_...` 继承的实验配置，都必须包含以下覆盖：

```python
MY_NEW_EXPERIMENT = LazyDict(dict(
    defaults=[
        "/experiment/cosmos_predict2p5_2B_reason_embeddings_action_conditioned_rectified_flow_bridge_13frame_480_640_",
        {"override /net": "cosmos_v1_2B_action_chunk_conditioned"},
        {"override /data_train": "my_dataset_train"},
        {"override /data_val": "my_dataset_val"},
        {"override /checkpoint": "local"},   # 使用本地存储
    ],
    job=dict(group="my_group", name="my_experiment_name", project="cosmos_predict2_action_conditioned"),

    # ★ 必须：关闭 S3 上传（callbacks 的 save_s3 绑定到此字段）
    upload_reproducible_setup=False,

    # ★ 必须：覆盖祖父实验的 S3 enabled=True
    checkpoint=dict(
        load_path="/path/to/pretrained.pt",
        load_training_state=False,
        strict_resume=False,
        save_to_object_store=dict(enabled=False),
        load_from_object_store=dict(enabled=False),
    ),

    # ★ 必须：覆盖祖父实验的 straggler_detection=True
    # ★ 必须：覆盖 viz_online_sampling 的硬编码 save_s3=True
    trainer=dict(
        straggler_detection=dict(enabled=False),
        callbacks=dict(
            every_n_sample_reg=dict(save_s3=False),
            every_n_sample_ema=dict(save_s3=False),
        ),
    ),

    # 业务相关参数
    model=dict(config=dict(
        net=dict(action_dim=14, ...),
    )),
    ...
))
```

训练命令：

```bash
torchrun --nproc_per_node=1 --master_port=12341 \
  -m scripts.train \
  --config=cosmos_predict2/_src/predict2/action/configs/action_conditioned/config.py \
  -- experiment=my_experiment_name \
     ~dataloader_train.dataloaders   # ★ 必须：删除祖父实验遗留的 dataloaders 键
```
