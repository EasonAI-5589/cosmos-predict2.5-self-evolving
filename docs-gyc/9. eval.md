# RoboTwin Val 评估记录

## 数据集结构

- **train**: 100 pcp + 80 pob
- **val**: 20 pob（pob_0080 ~ pob_0099），无 pcp

## 推理（生成视频）

修改 `assets/action_conditioned/robotwin/inference_params.json` 中的 `start` / `end`（Python 切片，end 不含），然后运行：

```bash
source .venv/bin/activate
bash scripts/inference_robotwin_val.sh
```

或手动运行：

```bash
source .venv/bin/activate
export HF_HOME=/mnt/gyc_ckp/hf_cache
export HF_HUB_OFFLINE=1
export CUDA_VISIBLE_DEVICES=0
export TORCHINDUCTOR_COMPILE_THREADS=4

python examples/action_conditioned.py \
  -i assets/action_conditioned/robotwin/inference_params.json \
  -o outputs/action_conditioned/robotwin_val_iter74k \
  --config-file cosmos_predict2/_src/predict2/action/configs/action_conditioned/config.py \
  --checkpoint-path /mnt/gyc_ckp/training_outputs/cosmos_predict2_action_conditioned/gyc_robotwin/robotwin_14d_8gpu/checkpoints/iter_000074000/model_ema_bf16.pt \
  --experiment cosmos_predict2p5_2B_action_conditioned_rectified_flow_robotwin_14d_13frame_256x320
```

输出目录：`outputs/action_conditioned/robotwin_val_iter74k/`，每条样本生成 `<id>_chunk.mp4`。

## 生成对比视频

```bash
source .venv/bin/activate
python scripts/eval_robotwin_compare.py --gen_dir outputs/action_conditioned/robotwin_val_iter74k
```

- 加 `--force` 可强制覆盖已有的对比视频
- 输出文件：`<id>_compare_3.mp4`（左：GT，右：生成，上方标注帧号）
