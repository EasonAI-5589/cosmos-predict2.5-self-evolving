## 关键实现细节

- **Value returns**：`compute_monte_carlo_returns(terminal_reward=1.0, gamma=0.99)`，`success_default=True`。当前 RoboTwin 数据无 reward signal，只算占位 returns 让 pipeline 跑通；真正有判别力的 value 等后续 simulator rollout 数据（docs-gyc/14）。
- **Value frame 注入**：`_maybe_append_value_frame()` 沿 T 维 cat 到 `latent_state` 末尾。
- **action_emb pad**：`action_conditioned_minimal_v1_lvg_dit.py` 对 `action_emb_B_D` 沿 T 维 pad 0，匹配 `condition_video_input_mask_B_T` 的 T=6（value frame 不接受 action modulation）。
- **Callback 临时 disable**：CLI 上 `~trainer.callbacks.every_n_sample_reg` / `_ema`。原因：decode latent T=6 → 视频 21 帧 (1+5×4)，与 GT 17 帧 stack 报错。loss 计算在 latent 空间不受影响。
- **推理路径 TODO**：`cosmos_predict2/action_conditioned.py` 的 `generate_samples_with_latents_from_batch` 需在 `tokenizer.decode` 前 strip 掉最后一个 value latent（训完再补）。
