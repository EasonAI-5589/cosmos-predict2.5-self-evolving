## 关键实现细节

跟 V0.1.1 共享同一套 value-frame 改动：
- `_maybe_append_value_frame()` 沿 T 维 cat 到 latent
- `action_emb` pad 0 匹配 condition_video_input_mask 的 T=10
- Callback `every_n_sample_reg/_ema` 训练时 disable（避免 decode/stack 报错）
- **推理路径 TODO**：`generate_samples_with_latents_from_batch` 解码时需 strip value latent

Value returns：`compute_monte_carlo_returns(terminal_reward=1.0, gamma=0.99)`，`success_default=True`，placeholder 让架构跑通；真正的 value 训练等 simulator rollout 数据。
